# Educational authoring files

These files contain hidden educational content. Do not open, diff or print records/locales in player-facing development output. Use neutral filenames and `npm run content:report` for aggregate inspection.

Drafts and source-checked research are not playable releases. Only explicit reviewed, digest-approved records pass publication. The generated runtime catalog contains selection metadata; the full selected record is loaded privately on demand. See [the workflow and spoiler-free pilot report](../../docs/MYSTERY_LIBRARY.md).
