# Roadmap

1. Foundation: title screen, shared GitHub workflow, safe launcher, build publication, version-aware title refresh, documentation, and infrastructure tests.
2. Asset agreement with Claude: compare modest Earth representation options, choose a licensed small sample, document coordinates, UVs, formats, and budgets. Do not commit to a cube-sphere or giant tile hierarchy.
3. First interactive Earth: direct rotation under the camera, smooth continuous zoom, tested coordinate picking, resource lifecycle, accessibility input alternatives, performance baseline.
4. First educational loop: review the independent five-clue headless engine and Claude's Earth together; map keyboard/controller confirmation to centered coordinates, reveal the intended target and explanation, explicitly continue, and validate return-to-title update deferral. Education Mode has no scores, timers, grading, formal rounds, or predetermined progression.
5. Visual progression: evaluate satellite imagery, terrain, oceans, atmosphere, and progressive detail against measured budgets.
6. Independent political, label, and educational overlays; expand content with attribution, border policy, localization, and accuracy review.

Each milestone needs a small reviewable PR, explicit acceptance criteria, test evidence, and updated decisions. These are ordered goals, not delivery-date commitments.
